# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful. Criticise ideas and code, not people.
- Assume good intent. Ask before you conclude.
- No harassment, no insults, no discrimination of any kind.
- Keep discussions on the subject of the project.

This applies to issues, pull requests, discussions and all other project spaces.

## Report a problem

Report unacceptable behaviour to the maintainer in private: open a [private security advisory](https://github.com/falhad/mindroot/security/advisories/new) and mark it as a conduct report, or contact [@falhad](https://github.com/falhad) directly. Reports stay confidential.

The maintainer can remove comments, commits and contributions that do not follow this Code of Conduct, and can block a person who repeats the behaviour.
